☠️ ONE PIECE — The Grand Line

*The sea is calling. Set your course, find your crew, and chase your dream.*

A One Piece-inspired interactive website where users can explore the Straw Hat Pirates, create their own pirate profile, and begin their journey across the Grand Line.

🌊 About the Project

One Piece — The Grand Line is a front-end web development project inspired by the world of *One Piece*. It combines a pirate-themed visual design with interactive website functionality, including crew exploration, profile creation, form validation, and browser-based data storage.

The project is built using HTML, CSS, and vanilla JavaScript, with no front-end framework required.

✨ Features

- **Grand Line Home Page:** A themed landing page featuring the pirate journey, crew previews, and navigation.
- **Crew Members:** Explore the Straw Hat Pirates through an interactive crew carousel.
- **Join the Crew:** Create a custom pirate profile by entering personal details, selecting a crew role, describing a dream, and uploading a profile picture.
- **Form Validation:** Validate required fields, email format, password length, pirate name, crew role, and dream description.
- **Profile Picture Preview:** Preview an uploaded profile picture before submitting the form.
- **Pirate Profile Management:** Display pirate profile information and crew members using browser storage.
- **Login Page:** Access the login interface for the pirate-themed experience.
- **Responsive Navigation:** A mobile navigation menu for easier browsing.
- **Interactive UI:** JavaScript-powered interactions, animations, and dynamically generated crew content.

🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure and content |
| CSS3 | Styling, layouts, animations, and responsive design |
| JavaScript (ES6+) | Interactions, form validation, and dynamic content |
| Web Storage API | Browser-based persistence of crew data |
| FileReader API | Reading uploaded profile pictures |
| Git & GitHub | Version control and project hosting |
